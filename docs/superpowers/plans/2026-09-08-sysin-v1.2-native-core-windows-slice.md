# SysIn V1.2 Native Core + Windows x64 Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first native SysIn preview as a side-by-side Windows x64 vertical slice proving universal telemetry contracts, supervised collectors, immutable snapshots, a purpose-built responsive Spectrum TUI, real local Overview telemetry, and basic CLI/JSON without replacing the installed V1.1 runtime.

**Architecture:** Windows-specific collectors translate real machine data into universal typed observations. A telemetry store creates coherent snapshots consumed independently by the CLI and TUI. The TUI renders through a virtual-testable framebuffer/diff engine with fixed responsive breakpoints and semantic Spectrum colors. The installed V1.1 PowerShell runtime stays untouched throughout this workstream.

**Tech Stack:** C# 14 / .NET 10 LTS; `xunit.v3` 4.0.0; `Microsoft.NET.Test.Sdk` 18.9.0; `System.Management` 10.0.12 for Windows GPU identity; `System.Diagnostics.PerformanceCounter` 10.0.11 only for explicitly supported Windows performance-counter telemetry; built-in `System.Net.NetworkInformation`, `System.IO.DriveInfo`, `System.Text.Json`, and P/Invoke for low-cost Windows CPU/memory primitives.

**Spec:** `docs/superpowers/specs/2026-09-08-sysin-v1.2-universal-mesh-design.md`

## Global Constraints

- V1.1 PowerShell runtime, launcher, installer, release manifest, and existing PowerShell tests remain unchanged in this workstream.
- The native preview runs only from its explicit build/publish output; it must not replace `%LOCALAPPDATA%\Programs\SysIn` or the installed `sysin` command.
- Shared projects target `net10.0`; Windows-only API/package usage remains inside `SysIn.Platform.Windows`.
- Nullable reference types, implicit usings, deterministic builds, and warnings-as-errors are enabled for native projects.
- No View/TUI code may call Windows/provider APIs directly.
- Unknown, unsupported, unavailable, permission-required, and provider-error metrics are explicit states and never numeric-zero placeholders.
- Distinct GPUs remain distinct devices. No GPU counter is assigned by WMI/list position or guessed identity.
- Rendering, collection, and future Mesh synchronization remain independent clocks. Balanced target is 20 FPS; actual FPS is measured separately.
- No busy-wait loops; collector failures/timeouts must not block rendering.
- No administrator requirement, account, Mesh, cloud telemetry, service, scheduled task, PATH mutation, migration, or destructive system action occurs here.
- The Overview must use available terminal space and locked Spectrum subsystem identity. A V1.1-style tiny upper-left island or large unexplained dead zone is a HOLD.
- This workstream creates Preview evidence only. It cannot authorize Stable or a GitHub Release.

```csharp
namespace SysIn.Core;

public readonly record struct MetricId(string Value);
public readonly record struct DeviceId(string Value);
public readonly record struct ProviderId(string Value);
public readonly record struct CollectorId(string Value);

public enum UnitId { None, Percent, Bytes, BytesPerSecond, Celsius, Hertz, Watts, Rpm, Seconds }
public enum MetricAvailability { Available, Unsupported, Unavailable, PermissionRequired, ProviderError }
public enum MetricFreshness { Fresh, Aging, Stale }
public enum MetricQuality { Direct, PlatformNative, GenericFallback }
public enum DeviceKind { System, Cpu, Gpu, Memory, PhysicalStorage, Volume, NetworkAdapter, Process, Sensor, Battery }
public enum DeviceRole { Integrated, Discrete, Display, HighPerformance }

public sealed record DeviceDescriptor(
    DeviceId Id, DeviceKind Kind, string Name, string? Vendor, string? Model,
    IReadOnlySet<DeviceRole> Roles);

public sealed record MetricObservation(
    DeviceId DeviceId, MetricId MetricId, double? Value, UnitId Unit,
    DateTimeOffset ObservedAt, ProviderId ProviderId, MetricQuality Quality,
    MetricAvailability Availability, MetricFreshness Freshness)
{
    public static MetricObservation Available(DeviceId deviceId, MetricId metricId, double value,
        UnitId unit, ProviderId providerId, MetricQuality quality, DateTimeOffset observedAt) =>
        new(deviceId, metricId, value, unit, observedAt, providerId, quality,
            MetricAvailability.Available, MetricFreshness.Fresh);

    public static MetricObservation Unavailable(DeviceId deviceId, MetricId metricId, UnitId unit,
        ProviderId providerId, DateTimeOffset observedAt, MetricAvailability availability)
    {
        if (availability == MetricAvailability.Available)
            throw new ArgumentOutOfRangeException(nameof(availability));
        return new(deviceId, metricId, null, unit, observedAt, providerId,
            MetricQuality.GenericFallback, availability, MetricFreshness.Stale);
    }
}
```

`DeviceIdFactory.Create` normalizes stable parts with `Trim().ToUpperInvariant()`, hashes `kind + U+001F + parts` with SHA-256, and returns `<kind-lower>:<first-24-lowercase-hex>`.

- [ ] **Step 3: Implement bounded execution**

```csharp
using var timeout = CancellationTokenSource.CreateLinkedTokenSource(cancellationToken);
timeout.CancelAfter(collector.Timeout);
var started = timeProvider.GetTimestamp();
try
{
    var values = await collector.CollectAsync(timeout.Token);
    store.PublishRange(values);
    MarkSuccess(collector.Id, timeProvider.GetElapsedTime(started));
    return CollectorRunResult.Success(values.Count);
}
catch (OperationCanceledException) when (!cancellationToken.IsCancellationRequested)
{
    MarkFailure(collector.Id, "Timeout", timeProvider.GetElapsedTime(started));
    return CollectorRunResult.Failure("Timeout");
}
catch (Exception ex)
{
    MarkFailure(collector.Id, ex.GetType().Name, timeProvider.GetElapsedTime(started));
    return CollectorRunResult.Failure(ex.GetType().Name);
}
```

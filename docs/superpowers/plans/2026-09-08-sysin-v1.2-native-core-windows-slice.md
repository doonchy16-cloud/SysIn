# SysIn V1.2 Native Core + Windows x64 Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first native SysIn preview as a side-by-side Windows x64 vertical slice proving universal telemetry contracts, independently scheduled supervised collectors, coherent snapshots, a purpose-built responsive Spectrum TUI, real local Overview telemetry, and basic CLI/JSON without replacing the installed V1.1 runtime.

**Architecture:** Windows collectors translate real machine data into universal typed observations. `CollectorScheduler` runs collectors on cadences independent of rendering; `CollectorSupervisor` contains faults and publishes collector-health data. `TelemetryStore` creates immutable snapshots containing devices, latest metric truth, and collector health. CLI and TUI consume those snapshots independently. The TUI uses a virtual-testable framebuffer/diff engine and responsive Spectrum components. Installed V1.1 stays untouched.

**Tech Stack:** C# 14 / .NET 10 LTS; `xunit.v3` 4.0.0; `Microsoft.NET.Test.Sdk` 18.9.0; `System.Management` 10.0.12 for Windows GPU identity; `System.Diagnostics.PerformanceCounter` 10.0.11 only where a Windows GPU counter can be associated to a device without guessing; built-in `System.Net.NetworkInformation`, `System.IO.DriveInfo`, `System.Text.Json`, and Windows P/Invoke for CPU/memory primitives.

**Spec:** `docs/superpowers/specs/2026-09-08-sysin-v1.2-universal-mesh-design.md`

## Global Constraints

- V1.1 PowerShell runtime, launcher, installer, manifest, and existing PowerShell tests remain unchanged.
- Native preview runs from explicit build/publish output only; it does not replace `%LOCALAPPDATA%\Programs\SysIn` or the installed `sysin` command.
- Shared projects target `net10.0`; Windows-only API/package usage stays inside `SysIn.Platform.Windows`.
- Nullable, implicit usings, deterministic builds, and warnings-as-errors are enabled.
- View/TUI code never calls Windows/provider APIs directly.
- Missing telemetry is explicit; numeric zero is never a missing-data sentinel.
- Distinct GPUs remain distinct; no GPU counter is assigned by enumeration position or guessed identity.
- Rendering and collection are independent clocks. Balanced target is 20 FPS; measured actual FPS is separate.
- No busy-wait loops. A slow/broken collector cannot block rendering or another collector.
- No admin requirement, account, Mesh, cloud telemetry, hidden service, scheduled task, PATH mutation, migration, or destructive action occurs here.
- Overview must use available screen space and Spectrum subsystem identity; V1.1-style top-left island/dead-space behavior is HOLD.
- This workstream produces Preview evidence only; it cannot authorize Stable or a GitHub Release.
